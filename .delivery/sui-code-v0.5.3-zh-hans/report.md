基线为实机启动验收通过的 v0.5.2：`7275179bd483b1587113b76d50f8d23e202a0d87`；本轮任务文档基线 `738f34f32bf7df518e0d17bcb57068cd9c34e04f`。开发分支 `sui-code/v0.5.3-zh-hans-kit`。用户已确认的是 v0.5.2 的 ARM64 平板启动，本报告不把该结果延伸到新版本。

## 实现范围

- 独立 `dev.suicode.localization.zh-hans` / `1.0.0` / `zh-Hans` `.suik`，不是原 `dev.suicode.example.zh-hans` 的12条开发示例。使用正式 SUIKPKG 格式、完整 Manifest、受限资源路径及逐文件 SHA-256。
- **732 个英文默认键与 732 个中文值**，不把中文内置到 APK。只申请 `ui.localization`，无依赖、脚本、运行器或工具链，不安装 Ubuntu/JDK/Python/GCC。
- Files、Find、Languages、Packages、Settings、Project、文件操作、编辑、运行及调试接入共享快照；包含菜单、设置说明、状态、变量格式化与常用 Snackbar。编辑器菜单缓存随语言快照失效，用户路径/文件名/源码/终端输出和配置枚举标识保持原值。
- 在无环境且安装器空闲时，第一运行引导可使用既有暂缓配置能力访问被动扩展包。它不伪装 Ubuntu 就绪；运行和调试仍检查真实环境；安装运行期间不能通过新增继续按钮绕过引导。
- 修复暂缓首次配置后，未安装发行版的 `jcodeUserReady=null` 被误判为永久初始化中的等待逻辑；不改变安装标志，真实检测和运行中的安装仍等待。
- 保留 v0.5.2 的字面占位符扫描器、本地化可选初始化、偏好降级及 SuiStartup 日志。不恢复 Android ICU 曾拒绝的正则。
- Schema、完整规范、SDK、离线工具、正式中文包及12条兼容示例保持一致。未知/安全键、错误占位符、超限资源和篡改数据继续拒绝。

## 信任与安装

**语言包未签名，来源未验证。** 当前配置没有可用的官方包私钥；没有伪造官方签名、生成替代官方根或改动信任库。完整性校验有效并不等于官方签名。安装审阅的来源、权限和签名提示由宿主保护，继续显示英文；普通包不能覆盖这些文本。

1. 直接覆盖升级 APK，禁止卸载、清除应用数据或重装 Ubuntu。
2. Packages → Import .suic / .suik，选择独立 `sui-code-zh-hans-1.0.0.suik`。
3. 审阅 `Unverified publisher`，确认 `I trust this unverified publisher`，同意唯一权限 `ui.localization`，点击 `Confirm plan and install`。不需要选择 Java/C++/Python Kit。
4. Packages → Interface language → 简体中文。可立即切换并重启保留；需要英文时选择 English。
5. 禁用或卸载语言包后回退英文。重新启用按现有审阅流程执行，可以恢复或重新选择中文。卸载不删除用户文件、环境或工具；恢复归档沿用现有存储策略保留，但不再提供活动资源。
